# Harmony Music School

Harmony Music School is a modern, responsive Single Page Application (SPA) designed to showcase a premium music academy. The site offers visitors an interactive course catalog, a student dashboard (for managing lessons and logging practice sessions), and a lesson booking system.

## Features

- **Interactive Navigation**: Seamless switching between different sections (Home, Courses, Dashboard, Booking) without full-page reloads.
- **Premium Dark Mode Aesthetic**: Visual layout with glassmorphic cards, glowing accents, and smooth hover effects.
- **Courses Explorer**: Dynamic filtering of courses by instrument type (Piano, Guitar, Violin, Voice, Drums) and difficulty level.
- **Mock Student Dashboard**:
  - Live progress tracker.
  - Upcoming class schedule.
  - Interactive practice logger (adds sessions and updates hours).
  - Mock messaging center to contact instructors.
- **Online Booking System**: Date/time selectors and validation-friendly booking form.

## Technology Stack

- **HTML5**: Semantic structure and SEO metadata.
- **CSS3**: Variables, flexbox/grid layout, CSS glassmorphism, keyframe animations.
- **JavaScript (Vanilla)**: DOM manipulation, state management, and application interactivity.

## Getting Started

1. Double-click `index.html` to open the web application in any modern browser.
2. Alternatively, run a local development server in this directory:
   ```bash
   npx serve .
   ```
